There are 3 main paths at the moment for contributing:

## Share it

Seriously, just get the word out so other people can find this. Remember, [Ratatouille model](/plan)!

## Join the discussion

For now, discussions will be on [GitHub](https://github.com/orgs/joinproject2027/discussions), but don't be afraid to join if you're not a developer! GitHub Discussions are like a normal forum, you don't need to know how to code to use them.

## Funding

Currently, this is a one person, self-funded project. Unfortunately, I don't have infinite runway, so eventually I will need to get a job and pay the bills. I would very much like for that job to be working on this project, so if you are interested in helping me achieve that, send me an email at [hello@joinproject2027.org](mailto:hello@joinproject2027.org).

I'm also open to crowd funding if there is enough support from the community, but that will all be part of the discussion!
